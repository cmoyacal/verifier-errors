RLVR Hacking Simulator

A neural contextual bandit: eight prompts, each with 16 correct responses, 16 hacks the verifier wrongly accepts, and 16 rejected responses. A small network scores every response from its features, so one update moves all of them. Change the initial hacked share, the rejected features, or the step size, and watch when reward hacking emerges and how raw and projected audit correction respond.

Selective control moves up and to the left: fewer hacks and more correct responses.

The network has four inputs, one hidden layer of 16 tanh units, and a scalar output; offsets fix the initial probabilities, with initial acceptance 2/3. Features follow the paper's Gaussian construction. Gradients are exact sums over all prompts and responses. This page re-implements the setup in the browser for intuition, so its numbers do not reproduce the paper's runs.
